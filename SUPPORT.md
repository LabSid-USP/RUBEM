# Support

- **Documentation**: start with the [user guide and tutorials](https://rubem.readthedocs.io).
- **Questions and ideas**: use [GitHub Discussions](https://github.com/LabSid-USP/RUBEM/discussions) or write to [rubem.hydrological@labsid.eng.br](mailto:rubem.hydrological@labsid.eng.br).
- **Bugs and feature requests**: open an issue with the matching form on the [issue tracker](https://github.com/LabSid-USP/RUBEM/issues). Please do not use the tracker for support questions.
- **Security problems**: follow the [security policy](SECURITY.md) instead of opening a public issue.
